## Сообщить об уязвимости

**Не создавайте публичный issue** для уязвимостей безопасности.

Используйте [приватный Security Advisory](https://github.com/mklishin/headhunter-boost/security/advisories/new) на GitHub. В описании укажите:

- Версию скрипта
- Тип уязвимости
- Шаги воспроизведения
- Возможные последствия

Ответ — в течение 5 рабочих дней.

---

## О данных пользователя

Скрипт не передаёт никаких данных на внешние серверы:

- **Resume ID** хранится только локально в GM-хранилище Tampermonkey
- **ID вакансий** и счётчики хранятся только локально
- **Шаблоны писем** хранятся только локально
- Скрипт взаимодействует исключительно с `*.hh.ru` — никаких других сетевых запросов нет
