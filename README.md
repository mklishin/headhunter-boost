## Что это

HeadHunter Boost — Tampermonkey-скрипт для автоматической отправки откликов на [hh.ru](https://hh.ru). Работает прямо в браузере без установки Node.js или системы сборки. Все настройки — через встроенную панель.

---

## Возможности

| | |
|---|---|
| **Автоцикл** | Перебирает все кнопки «Откликнуться» на странице |
| **Умный пропуск** | Обнаруживает сложные вакансии по изменению URL после клика |
| **SPA back-nav** | `history.back()` — JS-контекст не уничтожается, цикл продолжается |
| **Шаблоны писем** | До 5 шаблонов, `{JOB_TITLE}`, случайный выбор |
| **Рандом задержки** | Гаусс [min–max], ротация каждые 4–7 откликов |
| **Антибот-ввод** | `click()` 60% / `focus+Enter` 40%, полный keydown/keypress/keyup |
| **Мульти-резюме** | До 5 резюме, авто-загрузка заголовка, радиокнопка |
| **Лимит hh.ru** | Обнаружение 200 откликов/сутки, остановка + звуковой сигнал |
| **Подсветка карточек** | Зелёная/серая полоса на обработанных вакансиях |
| **Список пропущенных** | Кнопка ⏩ — попап со всеми пропущенными + ссылки |
| **Сохранение состояния** | Переживает перезагрузку, SPA-навигацию, bfcache |
| **Журнал отладки** | RAF-дебаунс, подробные ошибки, копирование с Unix-временем |

## Быстрый старт

1. Откройте поиск вакансий на hh.ru с выбранным резюме
2. В панели (правый нижний угол) откройте **⚙️ Настройки** → добавьте Resume ID → сохраните
3. Нажмите **▶️ НАЧАТЬ ОТПРАВКУ**

Resume ID — длинный буквенно-цифровой код из URL вашего резюме после `/resume/`.

> Лимит hh.ru — **200 откликов в сутки**. При достижении скрипт останавливается автоматически.

## Настройки

| Параметр | По умолчанию | Описание |
|---|---|---|
| Resume ID (до 5) | — | ID из URL резюме. Метка загружается с hh.ru автоматически |
| Задержка | 3000 мс | Пауза между откликами, мин. 1500 мс |
| Рандомизация | Выкл | Гауссово распределение в [min, max], ротация 4–7 откликов |
| Шаблоны писем | 3 шаблона | До 5, `{JOB_TITLE}`, до 1500 символов |
| Случайный шаблон | Выкл | Требует ≥ 2 шаблонов |

**Резюме и шаблоны не сбрасываются кнопкой «Сбросить сессию».**

## Отладка

Все ошибки видны в панели:
- `❌ LOOP ERROR:` + до 4 строк стека — падение основного цикла
- `❌ GM_setValue("key") failed:` — ошибка записи состояния
- `⚠️ humanInteract error:` — DOM-ошибка при клике, с резервным `.click()`
- `⚠️ fetchResumeTitle failed:` — сетевая ошибка при загрузке заголовка резюме
- `⚠️ getVacancyIdFromUrl parse error:` — сломанный URL вакансии
- `⚠️ getVacancyIdFromBtn: ID not found` — hh.ru сменил разметку карточки
- `⚠️ getJobTitleFromCard: title selectors returned nothing` — то же

Подробная трассировка (метод клика, HTTP-статус резюме) — только в `console.debug` (DevTools → Console → уровень Verbose).

## Состояние сессии

**Сбрасывается «Сбросить сессию»:**
- Счётчики · список пропущенных · список обработанных ID · журнал

**Не сбрасывается:**
- Резюме (ID + метки) · задержка · шаблоны · позиция панели

## FAQ

**Скрипт завис / не продолжается после сложной вакансии**  
Нажмите «назад» в браузере вручную — скрипт возобновится автоматически.

**Кнопки «Откликнуться» не находятся**  
hh.ru изменил разметку. В журнале появится `⚠️ getVacancyIdFromBtn`. Откройте [issue](https://github.com/mklishin/headhunter-boost/issues) с текущим значением `data-qa` кнопки.

**Отклик отправляется без письма**  
hh.ru отклонил текст (`aria-invalid="true"`). Скрипт намеренно очищает поле и отправляет без письма — лучше, чем не отправить совсем.

**Несколько вкладок одновременно**  
Не рекомендуется: вкладки конкурируют за GM-хранилище и могут сбросить `isRunning`.

## Архитектура

**SPA back-nav вместо перезагрузки** — hh.ru использует `history.pushState`. `history.back()` возвращает контекст без уничтожения JS. Тайм-аут 2 с для hard-nav fallback.

**Подсветка карточек** — `box-shadow: inset 3px 0 0` вместо `background-color`: не конфликтует с magritte-стилями hh.ru даже без `!important`. `MutationObserver` с `subtree:false` на контейнере списка — только реагирует на добавление новых карточек при скролле.

**ID вакансии** — атрибута `data-vacancy-id` нет (проверено май 2025). Берётся из href `[data-qa="serp-item__title"]`, либо из `?vacancyId=` URL переадресации.
