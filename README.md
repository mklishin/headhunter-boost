## Что это

Tampermonkey-скрипт: цикл по результатам поиска hh.ru, клик «Откликнуться», заполнение письма из шаблона, отправка. Сложные вакансии (анкеты, тесты) пропускаются автоматически без потери контекста.

---

## Установка

```
https://raw.githubusercontent.com/mklishin/headhunter-boost/main/headhunter-boost.user.js
```
Tampermonkey предложит установку по клику.

---

## Быстрый старт

1. Откройте поиск вакансий → выберите резюме
2. Панель появится в правом нижнем углу
3. **⚙️ Настройки** → добавьте Resume ID → Save
4. **▶️ НАЧАТЬ ОТПРАВКУ**

Resume ID — код после `/resume/` в URL вашего резюме.

## Возможности

| | |
|---|---|
| Автоцикл | Перебирает все кнопки «Откликнуться» на странице |
| Умный пропуск | URL-детект сложных вакансий после клика |
| SPA back-nav | `history.back()` — JS-контекст не уничтожается |
| Шаблоны писем | До 5, `{JOB_TITLE}`, случайный выбор |
| Рандом задержки | Гаусс [min–max], ротация каждые 4–7 откликов |
| Мульти-резюме | До 5 резюме, авто-загрузка заголовка с hh.ru |
| Антибот-ввод | `click()` 60% / `focus+Enter` 40% + keydown/press/up |
| Лимит 200 | Автоостановка + звуковой сигнал + попап |
| Подсветка карточек | `outline` + фон на обработанных вакансиях |
| Тёмная тема | 🌙/☀️ в Настройках, без перезагрузки |
| Сворачиваемая панель | Кнопка −, мини-счётчик в заголовке |
| Журнал | Только ошибки при старте; подробности в `console.debug` |

## Настройки

| Параметр | Описание |
|---|---|
| Resume ID (до 5) | ID из URL резюме; метка авто-загружается с hh.ru |
| Задержка | Фиксированная (мин. 1500 мс) или скрывается при рандомизации |
| Рандомизация | Диапазон [min≥100, max>min], ротация 4–7 откликов |
| Шаблоны писем | До 5, `{JOB_TITLE}`, до 1500 символов |
| Случайный шаблон | ≥ 2 шаблонов обязательно |
| Тёмная тема | Кнопка 🌙 в подвале Настроек |

**Резюме и шаблоны не сбрасываются при «Сбросить сессию».**

## Отладка

Ошибки в панели:
- `❌ Init failed [name]: ...` — сбой компонента при старте
- `❌ LOOP ERROR: ...` + стек — падение основного цикла
- `❌ GM_setValue("key") failed: ...` — ошибка записи состояния
- `⚠️ humanInteract error: ...` — DOM-ошибка, сделан резервный клик
- `⚠️ fetchResumeTitle failed: ...` — не удалось загрузить заголовок

Подробная трассировка (метод клика, HTTP-статус): `console.debug` → DevTools → Verbose.
