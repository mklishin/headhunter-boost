## Что это

Tampermonkey-скрипт: автоматически кликает «Откликнуться» на странице результатов поиска hh.ru, заполняет сопроводительное письмо из шаблона и отправляет отклик. Вакансии с анкетами и тестами пропускаются без потери контекста.

---

## Установка

```
https://raw.githubusercontent.com/mklishin/headhunter-boost/main/headhunter-boost.user.js
```

Tampermonkey предложит установку по клику. Или: Панель → Создать скрипт → вставить файл → Ctrl+S.

---

## Быстрый старт

1. Откройте поиск вакансий с выбранным резюме
2. Панель появится в правом нижнем углу
3. **⚙️ Настройки** → добавьте Resume ID → Save
4. **▶️ НАЧАТЬ ОТПРАВКУ**

Resume ID — код после `/resume/` в URL вашего резюме на hh.ru.

## Возможности

| | |
|---|---|
| Автоцикл | Все кнопки «Откликнуться» на странице |
| Умный пропуск | Обнаружение сложных вакансий по URL после клика |
| SPA back-nav | `history.back()` — JS-контекст не уничтожается |
| Шаблоны писем | До 5, `{JOB_TITLE}`, случайный выбор |
| Рандом задержки | Гаусс [min–max], ротация каждые 4–7 откликов |
| Мульти-резюме | До 5 резюме, авто-загрузка заголовка с hh.ru |
| Антибот-ввод | `click()` 60% / `focus+Enter` 40% + полный keydown/press/up |
| Лимит 200 | Автоостановка + звуковой сигнал + попап |
| Подсветка карточек | Outline + фон на обработанных вакансиях |
| Тёмная тема | 🌙/☀️ в Настройках, без перезагрузки |
| Сворачиваемая панель | Кнопка −, мини-счётчик в заголовке |
| Свобода действий | Копирование, вставка и контекстное меню всегда доступны |
| Журнал | Только ошибки при старте; подробности в `console.debug` |

## Настройки

| Параметр | Описание |
|---|---|
| Resume ID (до 5) | ID из URL; метка авто-загружается с hh.ru |
| Задержка | Фиксированная (≥1500 мс) или скрыта при рандомизации |
| Рандомизация | Диапазон [min≥100, max>min], ротация 4–7 откликов |
| Шаблоны писем | До 5, `{JOB_TITLE}`, до 1500 символов |
| Случайный шаблон | ≥ 2 шаблонов обязательно |
| Тёмная тема | Кнопка 🌙 в подвале Настроек |

**Резюме и шаблоны не сбрасываются при «Сбросить сессию».**

---

## Сброс сессии

| Сбрасывается | Не сбрасывается |
|---|---|
| Счётчики, список пропущенных | Резюме (ID + метки) |
| Список обработанных ID | Задержка, шаблоны |
| Журнал | Позиция панели |

## Отладка

- `❌ Init [name]: ...` — сбой компонента при старте (+ `console.error`)
- `❌ LOOP ERROR: ...` + стек — падение основного цикла
- `❌ GM_setValue("key") failed: ...` — ошибка записи состояния
- `⚠️ humanInteract error: ...` — DOM-ошибка, резервный клик
- `⚠️ fetchResumeTitle failed: ...` — не удалось загрузить заголовок

Verbose-трассировка (метод клика, HTTP-статус): DevTools → Console → Verbose.
