# 🚀 HeadHunter Boost

**Автоматическая отправка откликов на hh.ru**

Скрипт для Tampermonkey, который сам нажимает «Откликнуться», заполняет сопроводительное письмо из вашего шаблона и отправляет отклик — пока вы занимаетесь другими делами.

## Что это такое

HeadHunter Boost — кликер для автоматизации откликов на hh.ru.
<img width="430" height="457" alt="main" src="https://github.com/user-attachments/assets/ce9f3959-0a27-4ce6-a374-316e93e6054a" />


Он работает прямо в вашем браузере, не требует установки Node.js, сборки или редактирования кода. Все настройки — через встроенную панель управления на странице поиска.

## Как пользоваться

### 1. Откройте поиск вакансий

Перейдите на страницу поиска с выбранным резюме. Проще всего открыть hh.ru, выбрать резюме в шапке и нажать «Найти вакансии» — URL будет иметь вид:

```
https://hh.ru/search/vacancy?resume=ВАШ_ID&from=resumelist
```
На странице поиска выберите необходимые фильтры. Обзательно укажите страну поиска галочкой, потому что сейчас модалка при отклике в страну, отличную от страны в резюме, ломает флоу.
<img width="1000" height="594" alt="resume-to-serach" src="https://github.com/user-attachments/assets/f97f689a-36dc-4ef6-82ca-085829744217" />


### 2. Найдите панель управления
<img width="416" height="736" alt="settings" src="https://github.com/user-attachments/assets/a61e9550-31c2-4ae3-ac89-dc2d7de89743" />



В правом нижнем углу появится панель HeadHunter Boost. Её можно перетащить в любое место экрана.

### 3. Введите Resume ID

Нажмите **⚙️ Настройки**. В поле Resume ID вставьте ваш ID резюме — это длинный буквенно-цифровой код из URL вашего резюме:

```
https://hh.ru/resume/ab12cd34ef56gh78ij90kl12mn34op56
                     ^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^
                     вот этот код
```

### 4. Запустите

Нажмите **▶️ НАЧАТЬ ОТПРАВКУ**. Скрипт пройдёт по всем вакансиям на странице.

> Лимит hh.ru — **200 откликов в сутки** (май 2025). При достижении лимита скрипт остановится автоматически и покажет уведомление.

## Настройки

### Основные

| Параметр | Описание |
|---|---|
| **Resume ID** | ID резюме из URL (`hh.ru/resume/<ВАШ_ID>`) |
| **Задержка (мс)** | Пауза между откликами. Минимум 1500 мс. Отключается при включении рандомизации |

### Рандомизация задержки (рекомендуется)

Включается отдельным переключателем. При включении фиксированная задержка заменяется случайной — по гауссову распределению в диапазоне [Мин, Макс]. Задержка автоматически пересчитывается каждые 4–7 откликов.

| Параметр | Описание |
|---|---|
| **Мин. задержка** | Нижняя граница диапазона. Минимум 100 мс |
| **Макс. задержка** | Верхняя граница диапазона. Должна быть больше минимальной |

### Шаблоны сопроводительного письма

- До **5 шаблонов**
- Используйте `{JOB_TITLE}` — будет заменено на название вакансии
- До **1500 символов** в каждом шаблоне
- Можно включить **случайный выбор шаблона** (требует ≥ 2 шаблонов)
- Если hh.ru отклоняет текст письма — отклик отправляется без письма

> ⚠️ Шаблоны **не сбрасываются** кнопкой «Сбросить сессию». Для удаления — откройте Настройки и удалите вручную.

## Часто задаваемые вопросы

**Скрипт не находит кнопки «Откликнуться»**
hh.ru регулярно обновляет разметку страницы. Проверьте, что вы на странице результатов поиска (не на странице вакансии).
Заидите на страницу поичка вакансии на ХХ, убедитесь, что ораневое окошко повилось, намите Ctrl + Shift + R / Command + Shift + R.

**Скрипт завис после перехода на страницу вакансии**
Это редкий случай, когда `history.back()` не сработал. Нажмите кнопку «назад» в браузере вручную — скрипт возобновится автоматически.

**Не вижу панель управления**
Попробуйте обновить страницу. Убедитесь, что менеджер скриптов включён для hh.ru (иконка в панели инструментов браузера → скрипт должен быть активен).

**Отклик отправляется без сопроводительного письма**
hh.ru проверяет текст письма регулярным выражением. Если ваш шаблон не проходит проверку, скрипт намеренно очищает поле и отправляет отклик без письма — это лучше, чем не отправить совсем.

**Можно ли использовать одновременно несколько вкладок?**
Нет. Несколько вкладок с запущенным скриптом конкурируют за GM-хранилище и ломают состояние. Запускайте только в одной вкладке. Рекомендуется держать фокус на вкладке (держать вкладку открытой).

## Технические детали

<details>
<summary>Раскрыть</summary>

### Почему не открывает сложные вакансии в фоновой вкладке

Все вкладки `*.hh.ru` запускают этот скрипт. Если открыть сложную вакансию в фоне, её скрипт вызовет `GM_setValue("isRunning", false)` и сломает основной цикл. Поэтому сложные вакансии только логируются.

### Как работает SPA-навигация

hh.ru — React SPA. Переход на страницу сложной вакансии обычно происходит через `history.pushState`. После обнаружения скрипт вызывает `history.back()` — страница возвращается без перезагрузки и без потери JS-контекста. Тайм-аут 2 с защищает от случаев, когда hh.ru делает жёсткую навигацию.

### Откуда берётся ID вакансии

Атрибута `data-vacancy-id` на карточках hh.ru нет (проверено май 2025). ID извлекается из `href` ссылки заголовка вакансии, или из параметра `vacancyId` URL переадресации.
