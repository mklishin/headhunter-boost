# История изменений

## [6.4] — июнь 2025

### Добавлено
- Перехват событий видимости вкладки (`visibilitychange`) на уровне capture-фазы — hh.ru не получает уведомление о переключении вкладки
- `visibilityState` всегда возвращает `"visible"`, `document.hidden` всегда `false`
- CSS `user-select:text!important` — выделение текста и копирование всегда доступны
- Capture-phase stoppers для `copy/paste/contextmenu/selectstart` — hh.ru не может заблокировать эти действия

### Исправлено
- Панель управления исчезала после SPA-навигации hh.ru: MutationObserver теперь никогда не отключается и воссоздаёт панель при необходимости
- Все `catch {}` заменены на `catch (_) {}` — совместимость с движком Tampermonkey
- `step()` в `init()` теперь пишет в `console.error` — ошибки инициализации видны в DevTools даже если панель не создалась
- Константа `VERSION` обновлена до `6.4`

### Не реализовано (намеренно)
- Перезапись `EventTarget.prototype.addEventListener` — ломает React hh.ru и предотвращает инициализацию страницы. Использован безопасный capture-phase подход.

## [6.3] — июнь 2025

### Исправлено
- Заголовок панели в тёмной теме: добавлен `id="as-brand-span"`, CSS теперь попадает точно
- Подсветка посещённых вакансий: `setProperty` на корень + дочерние `div`, `outline` как дополнительный сигнал, throttled `subtree:true` observer
- Поле задержки скрывается (`display:none`) при включённой рандомизации вместо `disabled`/`opacity`
- `step()` пишет в `console.error`, не только в лог-панель
