# История изменений

## [6.2] — июнь 2025

### Улучшено логгирование и отладка
- Добавлен канал `dbg()` — подробная трассировка (метод клика, результат запросов) выводится только в консоль DevTools, не засоряет панель пользователя
- `persistState()` — каждый вызов `GM_setValue` обёрнут в try/catch; сбой записи виден в панели как `❌ GM_setValue("key") failed: ...`
- `clearSession()` — аналогично
- `humanInteract()` — try/catch с резервным `.click()` при ошибке DOM; ошибка логируется
- `getVacancyIdFromUrl()` — исключение парсера URL теперь логируется с фрагментом URL вместо безмолвного `null`
- `fetchResumeTitle()` — `catch {}` заменён на `catch(e)` с выводом `e.message` и HTTP-статуса
- Блок `catch` основного цикла — теперь выводит до 4 строк стека вместо одной: видно точное место падения
- Метод взаимодействия (`click()` / `focus+Enter`) перенесён из панели в `console.debug` — панель больше не засоряется техническими деталями каждой кнопки

### Исправлено
- Версия поднята до 6.2

---

## [6.1] — май 2025

### Добавлено
- Случайный выбор шаблона письма (≥ 2 шаблонов) — переключатель в Настройках
- `humanInteract()` — человекоподобное взаимодействие: `.click()` (60%) / `focus+Enter` (40%) с полным циклом keydown/keypress/keyup
- Микро-пауза 20–70 мс перед скроллом к карточке
- Предупреждение о фокусе — оверлей при потере фокуса вкладкой пока скрипт работает
- Подсветка посещённых вакансий — зелёная/серая полоса + бейдж на карточках
- Мульти-резюме — до 5 резюме с авто-загрузкой заголовка с hh.ru, радиокнопка для выбора активного
- `MutationObserver` для подсветки переключён на `subtree:false` — устранена избыточная нагрузка
- `applyVisitedStyles` обёрнут в RAF-debounce — DOM-прогулка один раз за кадр

### Исправлено
- Кнопка «Сохранить» в настройках: `async onclick` без `try/catch` молча падал при любом исключении — теперь обёрнут, ошибка видна пользователю
- Индикация успеха при сохранении настроек (`✅ Saved!` на 900 мс перед закрытием)
- Детальное логгирование сохранённых настроек (резюме, задержка, шаблоны)

## [6.0] — май 2025

### Добавлено
- Рандомизация задержки (распределение Гаусса) — диапазон [min, max], ротация каждые 4–7 откликов
- Обнаружение дневного лимита 200 откликов — остановка скрипта, тональный сигнал, попап
- Кликабельный счётчик «Пропущено» — попап со списком вакансий, ссылками и временем
- Настраиваемые шаблоны писем — до 5, сворачиваемые блоки, 1500 символов, `{JOB_TITLE}`
- Запасная отправка без письма при `aria-invalid="true"`
- Кнопка ↘️ для возврата панели в правый нижний угол
- Подсказка формата Resume ID в Настройках

### Исправлено
- `GM_notification` мёртвая директива — удалена
- `confirm` → `showConfirm` — не конфликтует с `window.confirm`
- `logApplication` — один блок вместо 6 отдельных RAF-задач
- `document.execCommand("copy")` — удалён, используется `navigator.clipboard`
- `mousemove` listener перетаскивания — `{passive: true}`
- Интервал опроса URL: 150 мс → 80 мс
