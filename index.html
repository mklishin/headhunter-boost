HeadHunter Boost

Автоматическая отправка откликов на hh.ru — шаблоны писем, умный пропуск сложных вакансий, человекоподобное поведение.

↓ Установить скрипт GitHub

Установка

Требуется расширение Tampermonkey. Нажмите кнопку ниже — появится диалог установки.

https://raw.githubusercontent.com/mklishin/headhunter-boost/main/headhunter-boost.user.js

Быстрый старт

Установите Tampermonkey

Chrome, Firefox, Edge, Opera — расширение доступно для всех основных браузеров.

Установите скрипт

Нажмите «Установить скрипт» выше — Tampermonkey покажет диалог подтверждения.

Откройте hh.ru

Перейдите на страницу поиска вакансий с выбранным резюме. Панель появится в правом нижнем углу.

Введите Resume ID и запустите

В настройках вставьте ID резюме из URL: hh.ru/resume/ВАШ_ID. Нажмите ▶️ НАЧАТЬ.

Возможности

🤖

Автоцикл

Перебирает все кнопки «Откликнуться» на странице поиска, не переходя на страницу вакансии.

⏩

Умный пропуск

Вакансии с тестами и анкетами обнаруживаются по URL после клика и пропускаются без потери контекста.

✉️

Шаблоны писем

До 5 шаблонов с плейсхолдером {JOB_TITLE}. Случайный выбор шаблона по желанию.

👤

Мульти-резюме

До 5 резюме. Заголовок каждого загружается автоматически с hh.ru.

🎲

Рандомизация

Задержка по распределению Гаусса в диапазоне [min–max]. Ротация каждые 4–7 откликов.

🖱️

Антибот-ввод

Чередование click() и focus+Enter с полным циклом keydown/press/up. Нет фиксированной сигнатуры.

🌙

Тёмная тема

Кнопка 🌙 в Настройках. Переключается мгновенно, запоминается между сессиями.

📋

Свобода действий

Копирование, вставка и контекстное меню всегда доступны. hh.ru не может заблокировать.

⛔

Лимит 200

Автоматическая остановка при достижении дневного лимита hh.ru. Звуковой сигнал и попап.

История версий

6.4
Защита от слежки.

Перехват событий видимости вкладки, спуфинг visibilityState, разблокировка copy/paste/contextmenu. Исправлено исчезновение панели после SPA-навигации React.

6.3
Надёжность интерфейса.

Заголовок панели виден в тёмной теме. Подсветка посещённых вакансий. Скрытие неактивных полей настроек.

6.2
Отладка.

dbg()-канал, защита каждого GM_setValue, полный стек ошибок цикла.

6.1
Крупное обновление.

Мульти-резюме, тёмная тема, сворачиваемая панель, подсветка карточек, случайный шаблон.

6.0
Рандомизация и лимиты.

Гауссова задержка, обнаружение лимита 200, настраиваемые шаблоны.
